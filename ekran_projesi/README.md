# 🚌 Samsun Akıllı Ulaşım Ekranı

Otobüs içi dijital bilgi ekranı sistemi - Gerçek zamanlı takip, etkinlikler ve hava durumu.

## 🚀 Hızlı Başlangıç

### 1. Gereksinimler
```bash
pip install fastapi uvicorn requests
```

### 2. Sunucuyu Başlat
```bash
python server.py
```

### 3. Tarayıcıda Aç
```
http://localhost:8001
```

## ⚙️ Ayarlar

Sağ üstteki **dişli simgesine** tıklayarak:
- Hat seçimi yapabilirsiniz
- Durak sırasını değiştirebilirsiniz

## 📁 Önemli Dosyalar

- `index.html` - Ana sayfa
- `style.css` - Tasarım (YENİ!)
- `script.js` - Frontend mantığı
- `server.py` - Backend API
- `data_provider.py` - Veri çekme işlemleri

## ⚠️ Eksik Dosya

**samsun_v25.db** dosyasını proje klasörüne eklemeyi unutma!

## 🎨 Özellikler

✅ Gerçek zamanlı otobüs takibi
✅ Leaflet harita entegrasyonu
✅ Biletinial etkinlik görselleri
✅ Hava durumu widget'ı
✅ Animasyonlu timeline
✅ Responsive tasarım

## 📸 Ekran Görüntüsü

Modern glassmorphism tasarım ile:
- Sol: Canlı harita + Etkinlikler
- Sağ: Durak zaman çizelgesi
- Alt: Sonraki durak banner'ı
